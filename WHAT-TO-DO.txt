HOW TO UPDATE
=============
1. Unzip this folder over your cheque-games project (same folders). Your computer will
   ask to replace files: say yes to all. Nothing has to be deleted.
2. Run:  npm install      (tsx moved to the normal dependencies)
3. Run:  npm test         (optional: checks the rules and the server)
4. Run:  npm run dev

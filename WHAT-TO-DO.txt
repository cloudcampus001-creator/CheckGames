HOW TO UPDATE
=============
1. Unzip this folder over your cheque-games project (same folders). Say yes to replace everything.
   Nothing has to be deleted.
2. Run:  npm install
3. Run:  npm test            (optional)
4. Run:  npm run dev

NEW FOR EVERYBODY
  - Profiles (name, face, level, stats, badges, rating), leaderboard, "Play online" matchmaking.
  - Turn clock chosen by the host, host can remove players in a game, nobody leaves after a game,
    host-written votes, DOUBLING (2-4 cards of the same number together), and a customisable look.
  - Fixes: A as the last card with 2 players; the red/black joker after a Jack.

ON RENDER (realtime server) - IMPORTANT
  - Push these files and let Render redeploy.
  - "Could not reach the game server" on some phones: the game now falls back by itself to plain
    requests (for networks that block WebSockets) and shows "Waking up the game server..." while a
    sleeping free server wakes up. Use the https:// address in NEXT_PUBLIC_REALTIME_URL, then redeploy Vercel.
  - To keep profiles and the leaderboard for good, add the Upstash variables on Render
    (UPSTASH_REDIS_REST_URL and UPSTASH_REDIS_REST_TOKEN), see .env.example.
  - To avoid the wake-up wait, keep it awake with a free pinger (cron-job.org every 10 minutes
    calling your Render address).
